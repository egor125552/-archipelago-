# Архипелаг — первая ходимая палуба бронекатера

Статус: практический тест общей палубной архитектуры.

Двухместный бронекатер использует общий vessel deck runtime, а не отдельную локальную систему.

## Игровой путь

1. Вход на бронекатер помещает игрока на малую палубу, а не автоматически за штурвал.
2. Стрелки перемещают игрока по локальной геометрии палубы; движение палубного игрока не управляет мотором.
3. В носовой части малой палубы находится закрытая дверь лестничного люка.
4. Первое действие у люка открывает дверь. Следующее действие начинает реальный временной переход по лестнице, длительность которого рассчитывается из геометрии и скорости перехода.
5. На верхней палубе рубки расположен физический пульт управления.
6. Действие у пульта занимает его и передаёт игроку управление бронекатером через существующее управление лодкой. Повторное действие освобождает пульт и возвращает режим ходьбы.
7. Прыжок с края верхней площадки может опустить игрока на нижнюю палубу, а с внешнего края палубы — сбросить в воду.

Обычный стандартный катер остаётся в прежнем простом режиме без ходимых палуб.
