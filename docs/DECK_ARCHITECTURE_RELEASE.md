# Архипелаг — релиз архитектуры палуб

Статус: архитектурный слой готов к использованию; конкретное тестовое судно намеренно не создаётся до отдельного запроса.

## Что входит в релиз

- строгая компиляция геометрии, топологии, ссылок, навигационной достижимости и конфигураций палуб;
- единый серверный runtime палуб, зон, дверей/люков/переходов, объектов, постов, воды, аварийного состояния и модульных правил;
- общий interaction API с серверной проверкой дистанции и многопользовательских claims;
- общий внутренний навигационный маршрут внутри существующего vessel-navigation слоя;
- persistence палубного состояния внутри существующего saved-world состояния судна;
- компактная сетевой репликация только runtime-состояния без передачи статической геометрии;
- reconnect/disconnect cleanup без вечных занятых постов;
- расширяемые deck-rule types и optional module degradation;
- акустические пути, пространственные источники и метаданные плавного перехода без создания второго аудиодвижка;
- обратная совместимость: суда без палуб продолжают использовать старый простой режим.

## Критерий релиза

Архитектура считается готовой как платформа после прохождения unit/integration/architecture gate/CI. Полная игровая приёмка ходимой палубы выполняется позже на конкретном тестовом судне только по отдельному запросу, как зафиксировано в интервью.
