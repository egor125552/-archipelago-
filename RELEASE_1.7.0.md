# Echo Archipelago 1.7.0

Release date: 2026-08-05

## Элитный катер-босс 1.0.0

- Угроза пять теперь имеет одну последовательную серверную цепочку: обычная группа, тяжёлый катер, отдельный элитный катер, физический командир и только затем награда.
- Элитный катер появляется исключительно после уничтожения тяжёлого катера. Он завершает текущую угрозу, но не объявлен окончательным боссом всей игры.
- Реализованы три последовательных слоя брони по 1000 и открывающийся после них корпус на 5000. Лишний урон не перескакивает через защищённый слой.
- Две независимые установки имеют отдельные ID, здоровье, точки запуска, наведение и ограниченные плотные очереди быстрых физических пуль.
- Попавшая в занятую лодку пуля повреждает корпус и отдельно рассчитывает прошедший человеку урон. Целая лодка защищает лучше, разбитая пропускает больше.
- Корабль физически перехватывает движущуюся лодку, держит боевую дистанцию, отрывается при опасном сближении и остаётся внутри карты.
- Бомбоотсеки выпускают конечную серию из трёх настоящих бомб через общую серверную физику мега-бомбы.
- После нуля корпуса корабль прекращает новые очереди и высаживает ровно одного командира. Командир использует общие автомат, пистолет, нож, физические бомбы, здоровье и смерть.
- Награда угрозы пять выдаётся один раз только после смерти командира.

## Интеграция и доступность

- Старая параллельная «финальная волна» угрозы пять отключена: больше нет двух конкурирующих финалов, лишних десятков врагов и перегруженной озвучки.
- Меню целей показывает только текущий слой, доступные установки, открытый корпус или физически появившегося командира.
- Добавлены короткие события для критического слоя, разрушения брони, раскрутки каждой установки, бомбового залпа, уничтожения корабля и высадки командира.
- Длительные и позиционные звуки проходят через общий аудиодвижок и используют существующие проверенные игровые аудиофайлы.
- Состояние босса, обеих установок и физических пуль реплицируется обоим клиентам с одним encounter ID.

## Проверка

- Добавлены детерминированные проверки появления после тяжёлого катера, трёх слоёв, независимых установок, пробития лодки, границ карты, конечного бомбового залпа, одного командира, одноразовой награды, очистки и двухклиентной репликации.
- Добавлен браузерный Chromium-сценарий полного жизненного цикла и отдельный GitHub Actions workflow релиза.
- Физический iPhone с VoiceOver остаётся отдельной ручной проверкой после публикации; автоматические проверки подтверждают структуру сообщений, общий аудиодвижок и отсутствие визуально обязательного действия.
