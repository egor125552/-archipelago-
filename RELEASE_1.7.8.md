# Релиз 1.7.8 — общая authority движения модульных судов

Дата: 2026-08-15

## Зачем нужен этот релиз

В 1.7.7 был исправлен реальный баг самого быстрого катера «Пятьдесят»: обычная legacy-физика лодок успевала изменить его скорость и координаты, после чего собственная физика 50 двигателей снова разгоняла катер. Это создавало заметную «пилу» скорости при постоянно зажатом газе.

Исправление 1.7.7 работало, но граница authority находилась внутри конкретного `stress-test-physics`. Если добавить новое архитектурное судно со своей `physics.mode: "module"`, разработчику пришлось бы помнить о legacy-слое и повторять ту же защиту вручную. Это противоречит правилу общей архитектуры судов.

## Что изменено

В 1.7.8 общий `vessel-runtime-v3` становится единственной границей между legacy boat-step и модульной физикой архитектурных судов.

Для каждого архитектурного судна с `physics.mode: "module"` runtime получает снимок движения, сделанный до legacy-step. Если тик чистый и не содержит физического контакта, перед вызовом конкретного physics-модуля runtime возвращает скорость к состоянию предыдущего настоящего тика. Поэтому старый ordinary-boat расчёт не может стать вторым хозяином скорости.

После работы модуля runtime проверяет, рассчитывал ли модуль координаты самостоятельно. Если модуль менял только скорость, общий runtime заменяет устаревшее legacy-перемещение чистым линейным движением, рассчитанным из предыдущей позиции и окончательной скорости модуля. Игроки на борту синхронизируются с итоговой позицией судна.

Если будущий модуль сам изменил `x` или `y`, runtime не выполняет вторую интеграцию координат. Это позволяет использовать как простые speed-only модули, так и полноценные custom-physics модули без двойного движения.

## Что происходит при реальном физическом воздействии

Authority не должна стирать смысловые последствия окружающего мира. Поэтому восстановление чистого движения не применяется, если судно в этом тике затронули:

- столкновение;
- таран;
- граница воды;
- подключение или отключение буксировки;
- активная буксировка;
- sonar guide snap.

Такие события сохраняют рассчитанные системой контактов координаты и скорость. После physics-модуля проверка выполняется повторно, поэтому даже событие, созданное самим будущим модулем в текущем тике, не будет перезаписано общей линейной интеграцией.

## Что изменилось в «Пятьдесят»

Из `stress-test-physics.js` удалены:

- чтение `previousStates`;
- собственный поиск collision/tow/boundary событий;
- собственное восстановление скорости;
- собственный пересчёт координат;
- собственная синхронизация пассажиров после такого пересчёта.

Теперь этот модуль снова отвечает только за своё содержательное поведение: считает число работающих из 50 двигателей, доступную долю тяги, ускорение, торможение, максимум 82 и профиль клиентского предсказания.

То есть 1.7.8 не копирует исправление 1.7.7 на новые суда, а удаляет необходимость в таких копиях.

## Регрессионные проверки

Добавлен отдельный `vessel-module-motion-authority.test.mjs` с условным будущим судном, не связанным с «Пятьдесят»:

1. Legacy-step оставляет скорость 36 при настоящей предыдущей скорости 52. Общая authority обязана дать будущему speed-only модулю стартовать от 52, а после его изменения скорости пересчитать чистое перемещение.
2. При настоящем `collision` authority не выдаётся: контактная скорость и позиция остаются нетронутыми.
3. Если будущий physics-модуль самостоятельно меняет координаты, общий runtime не перемещает судно второй раз.

Отдельный тест «Пятьдесят» теперь проверяет обратную сторону архитектуры: сам конкретный модуль больше не содержит private legacy bridge. При прямом вызове он использует только переданную текущую скорость и не трогает координаты.

Сохраняется интеграционная проверка через настоящий `stepFreeWorld`: на изолированной трассе «Пятьдесят» после полного газа обязан разгоняться без самопроизвольных провалов скорости.

## Загрузка в браузере

`free-roam-core-v8.js` теперь подключает `vessel-runtime-v3.js?v=1`. Это новый путь модуля и поэтому Safari не может использовать старую реализацию runtime из своего module cache.

`vessel-content-manifest.js` также переключён на `stress-test-physics.js?v=3`, чтобы обновлённый упрощённый модуль «Пятьдесят» гарантированно загрузился после релиза.

## Границы релиза

Баланс, максимальные скорости, ускорение, управление, столкновения, буксировка, вода, урон, оружие и звук этим релизом намеренно не меняются.

Это стабилизационный архитектурный багфикс: одна общая система получает authority, которая в 1.7.7 временно находилась внутри одного конкретного судна.
