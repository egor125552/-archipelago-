# Релиз 1.8.13 — стабилизация Bug Hunt и восстановление релизного процесса

Дата релиза: 2026-08-19

Версия 1.8.13 является восстановительным patch-релизом. После релиза 1.8.0 в `main` попали 13 коммитов без обязательного одновременного повышения версии и отдельного файла релиза. Это нарушило действующий `AGENTS.md`.

Версии 1.8.1–1.8.12 отдельно не выпускались. Номер 1.8.13 выбран по фактическому количеству коммитов после 1.8.0, чтобы восстановить последовательность без выдумывания несуществовавших релизов.

## Исправлено для игрока

- Spatial-подсказки перестали повторять один и тот же опасный край при удержании движения и получили более устойчивое поведение возле границ.
- Формулировки переходов и расстояний сделаны более человеческими; исправлены русские формы метров и добавлен позиционный звуковой ориентир для ближайших spatial-объектов и опасных краёв.
- Убрана ложная ready-зона у обычных объектов, добавлена устойчивость подсказок лестниц, входов и выходов к небольшим колебаниям дистанции.
- Вход пространственной лаборатории разнесён с торговцем, чтобы два взаимодействия не находились почти в одной точке.
- Предупреждение опасного края срабатывает раньше при беге и прыжке, но не спамит после уже начавшегося падения.
- Ручной запрос возрождения явно записывается в developer log без изменения штатной серверной механики respawn.
- Старые legacy-мега-бомбы больше не наносят урон игроку внутри отдельной spatial-локации только потому, что внешние и внутренние координаты x/y совпали.
- Запуск legacy-мега-бомбы из отдельной spatial-локации запрещён до появления полноценного распространения такого боя между пространствами; заряд при отказе не расходуется.
- Во время уже активного legacy-боя нельзя войти в отдельную spatial-локацию и использовать её как гарантированный safe-room. Выход из локации не блокируется.
- Для macOS/Safari добавлен watchdog потерянного `keyup` стрелок: если браузер или средство доступности проглотили отпускание клавиши, движение больше не должно оставаться включённым бесконечно.
- Исправлена корневая причина молчащих пунктов меню целей. Ручное описание выбранной боевой цели больше не подавляется фильтром автоматического боевого спама из-за слов `здоровье`, `прочность` или `осталось`.
- Временная отдельная очередь речи для меню целей полностью удалена. Меню снова использует обычный общий речевой контроллер и общую политику фильтрации.

## Тестовый набор

По прямой просьбе пользователя удалён большой исторический слой тестов, который проверял старые версии реализаций, cache/static детали и промежуточные Bug Hunt состояния.

В финальном состоянии:

- сохранены проверки серверной истины, сети и persistence;
- сохранены spatial, доступность и последние реальные регрессии;
- сохранены актуальный тяжёлый бой, основная мега-бомба, экономика и архитектура судов;
- сохранены два реальных браузерных E2E-сценария;
- удалён специализированный исторический heavy-browser workflow;
- Vessel architecture gate сокращён до оставшегося архитектурного ядра;
- игровой код в коммите очистки тестов не изменялся.

## Что было временным и не входит в итоговое поведение

В одном из Bug Hunt коммитов была добавлена отдельная FIFO-очередь для озвучки целей как гипотеза о причине пропущенной речи. Реальная проверка показала, что корневая причина находилась в боевом речевом фильтре. Очередь и её отдельный тест были удалены до этого релиза.

## Проверено автоматически

На итоговом коммите очистки `3d148eff` успешно завершились четыре GitHub Actions workflow:

- общий `Test Echo Archipelago`;
- `Vessel architecture gate`;
- `Diagnose Node tests`;
- `Verify game and Worker`.

В `Verify game and Worker` успешно прошли Node mechanics tests, установка Playwright, двухклиентные браузерные сценарии и проверка Cloudflare Worker bundle. Первый запуск браузерной проверки один раз завершился после аварийного выхода локального Wrangler без содержательной диагностической ошибки; повтор того же неизменённого коммита прошёл полностью.

## Проверено вручную

- До исправления пользователь в живой игре подтвердил связь бага меню целей с боевым речевым фильтром: UI показывал цель, но ручная фраза с `здоровье`/`прочность` могла не произноситься.
- Bug Hunt журналы дали воспроизводимые случаи пересечения legacy-боя со spatial-локациями и потерянного управления.

## Ещё не подтверждено на реальном устройстве после финального релиза

- Финальный 1.8.13 ещё не проходил отдельную пользовательскую приёмку на физическом Safari/VoiceOver после всех последних изменений.
- Не проводилась отдельная повторная сессия на намеренно плохой реальной сети после выпуска 1.8.13.
- Блокировка входа в spatial-локацию во время legacy-боя остаётся защитной границей совместимости, а не полноценной моделью распространения боя, взрывов, дверей и стен между пространствами.

## Релизный процесс

Этот релиз восстанавливает обязательное правило `AGENTS.md`: дальнейший законченный кодовый багфикс в `main` должен одновременно получать следующую patch-версию, обновление `package.json`, верхнюю запись `RELEASE_NOTES.md` и отдельный подробный русский файл релиза.

Предыдущий оформленный релиз: `RELEASE_1.8.0.md`.
