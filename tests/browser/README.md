# Browser repair regression

`heavy-repair-browser.mjs` запускает Chromium через Playwright, открывает настоящий `public`-корень игры и импортирует тот же production-контроллер тяжёлого катера, который работает в игре.

Сценарий воспроизводит журнал пользователя:

1. игрок находится в центральной части карты, где фиксированные 236 метров физически недостижимы;
2. у тяжёлого катера уничтожена оружейная установка, внутренний корпус остаётся цел;
3. катер обязан уйти к лучшей реально доступной точке;
4. физически остановиться;
5. один раз начать и завершить ремонт;
6. восстановить установку и вернуться в бой;
7. не принять временный запрет стрельбы за новую поломку.

Workflow: `.github/workflows/heavy-repair-browser.yml`.
