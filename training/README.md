# Тактическая нейросеть «Свободной бухты»

Система обучает маленькую рекуррентную сеть не клавишам игрока, а тактическим намерениям:

- удерживать позицию;
- сближаться;
- отходить;
- обходить цель слева;
- обходить цель справа;
- открывать огонь.

## Почему GitHub Actions

Обучение воспроизводимо и не требует держать MacBook включённым. Архив боёв скачивается по полному адресу `/api/training/archive?room=...` и проверяется на целых отложенных боях.

Gameplay replay не коммитится в публичный репозиторий. ZIP и временная сжатая память существуют только внутри GitHub runner и удаляются вместе с ним. В `main` попадают только квантованные веса, агрегированные метрики и текст самокритики. Для накопления опыта используется серверный архив, который уже содержит несколько последних боёв.

## Запуск в GitHub

1. Открыть Actions.
2. Выбрать **Train tactical neural policy**.
3. Нажать **Run workflow**.
4. Вставить полный URL архива. Вместо этого один раз можно создать repository variable `TRAINING_ARCHIVE_URL`.

Принятая модель автоматически коммитится в `main`. Отклонённая модель остаётся только в artifact `tactical-policy-review` и не заменяет действующую.

## Локальный запуск на Mac

```bash
python3 -m venv .venv-ai
source .venv-ai/bin/activate
python -m pip install numpy==2.3.5
python -m pip install torch==2.10.0 --index-url https://download.pytorch.org/whl/cpu
python training/train_policy.py --input ~/Downloads/echo-ai-training.zip --replay /tmp/echo-tactical-replay.json
python training/review_policy.py
npm test
```

Локальный и GitHub-запуск используют один и тот же код.

## Допуск модели

Сначала модель работает только в теневом режиме. Она получает те же наблюдения, что будущий противник, и выдаёт намерения, но старый ИИ продолжает полностью управлять врагами.

Автоматическая самокритика проверяет размер, число параметров, episode-level validation, превосходство над majority-baseline, переобучение и совпадение квантованного JavaScript-инференса с PyTorch.

Включать управление можно только после следующего этапа: детерминированных A/B-прогонов одинаковых боёв и seed, где сеть стабильно превосходит старый ИИ без нарушения правил боя.
