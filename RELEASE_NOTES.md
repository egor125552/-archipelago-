# Echo Archipelago 1.7.5

Дата релиза: 2026-08-12

## Исправлено

- Средний корабль больше не использует обычный мотор лёгкой лодки в удалённом сетевом аудиослое: профиль `medium-crew` теперь считается отдельным двигателем и для собственного, и для чужого судна.
- Обновлён cache-buster общего пространственного аудиослоя, чтобы Safari не мог продолжить использовать старую уже закэшированную версию после исправления.
- Регрессионная проверка теперь отдельно контролирует локальный и удалённый путь мотора среднего корабля.

Подробности: `RELEASE_1.7.5.md`.

Предыдущий релиз: `RELEASE_1.7.4.md`.
