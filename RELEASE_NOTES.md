# Echo Archipelago 1.7.3

Дата релиза: 2026-08-12

## Исправлено

- Магазин больше не падает, если в массиве флота есть пустой слот между существующими лодками.
- Общий ввод палубы больше не раздваивается между разными `?v=`-экземплярами одного bridge-модуля; повреждённая трюмная помпа снова получает нажатие и выдаёт штатное событие отказа.
- Регрессионный тест постов самого быстрого катера теперь использует тот же экземпляр `vessel-runtime`, что и игровой core, поэтому проверяет настоящий claim водительского кресла вместо второй независимой копии runtime.
- Принудительно обновлены cache-buster цепочки магазина, палубного input bridge и клиента среднего корабля, чтобы старые исправленные модули не оставались в Safari после предыдущего immutable-кэша.

Подробности: `RELEASE_1.7.3.md`.
