# Echo Archipelago 1.7.15

Дата релиза: 2026-08-16

## Исправлено

- Подробный журнал больше не копирует последние 20 секунд боя при каждом обычном пропуске номера серверного состояния.
- Пропуски серверных тиков сохраняются компактно через `server-state.compressedTicks`, поэтому их можно анализировать без многократного дублирования истории.
- Полный 20-секундный «чёрный ящик» теперь предназначен только для настоящих JavaScript, Promise и внутренних ошибок логгера.
- Одновременно хранится максимум четыре аварийных окна по 3000 записей, что ограничивает максимальный рост журнала при потоке ошибок.
- Подробная реконструкция боя сохранена: дорожки движения, управление, фазы, контрольные точки каждые 10 секунд, важные события, агрегаты выстрелов и ключевые точки траекторий мега-бомб остаются в журнале.
- Живой загрузчик переведён на исправленную реализацию `free-roam-developer-log-v4.js`.
- Добавлен regression-тест против повторного появления 232-мегабайтного сценария.
