# Echo Archipelago 1.7.8

Дата релиза: 2026-08-15

## Исправлено

- Возврат speed authority после legacy boat-step перенесён из конкретного катера «Пятьдесят» в общий runtime всех архитектурных судов с `physics.mode: "module"`.
- Будущему модульному судну больше не нужно самостоятельно знать о старой физике обычных лодок, восстанавливать скорость предыдущего тика или пересчитывать чистое перемещение.
- Реальные столкновения, таран, граница воды, буксировка и sonar guide snap по-прежнему имеют приоритет и не перезаписываются общей authority.
- Если будущий physics-модуль сам рассчитывает координаты, общий runtime распознаёт это и не интегрирует движение второй раз.
- Из `stress-test-physics` удалена частная копия legacy-bridge: модуль «Пятьдесят» снова отвечает только за 50 двигателей, доступную тягу, ускорение и ограничение скорости.
- Добавлены отдельные регрессионные тесты на условное будущее модульное судно: speed-only модуль, настоящее столкновение и модуль с собственной интеграцией координат.
- Сохранена интеграционная проверка реального «Пятьдесят» через общий `stepFreeWorld` с монотонным разгоном на полном газе.
- Клиентский core теперь подключает общий `vessel-runtime-v3.js?v=1`, а модуль физики «Пятьдесят» загружается с новым cache-buster `?v=3`.

Подробности: `RELEASE_1.7.8.md`.
